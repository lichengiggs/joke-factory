# 角色 d：配图

给已经入库的段子配一张多格漫画。用户会给编号，比如「画 006」。

## 输入

- `joke.md` 里 `## 006` 这一节的中文
- `$COMIC_TOOL`

## 你要做的

1. 把中文段子拆成 2 到 4 格。每格写一句画面描述，一句配文。
   - 画面描述写清场景、人物、动作、表情，具体到能画出来。
   - 配文从段子里取，不要新编。
   - 不出现人名、公司名、品牌名。
2. 调用（jpg 会自动压缩到 300 KB 左右，不要用 png，仓库会太大）：

```
$COMIC_TOOL --mode panels \
  --panel "画面描述|配文" \
  --panel "画面描述|配文" \
  --name 006 --out-dir images --format jpg
```

3. 确认 `images/006.jpg` 存在，不是空文件。
4. 在 `joke.md` 的 `## 006` 一节里，把下面这行插到「来源：」之前：

```
![006](images/006.jpg)
```

不要改文字，不要动其他条目。如果已有同名图片行，替换它，不要追加第二行。重复运行会覆盖旧图和旧链接，这是预期的。

## 失败

命令报错就原样贴出错误，不要自己画占位图，也不要编造图片路径。图片没生成成功，就不要往 `joke.md` 里插图片行。

画完只回复：已配图 006。
