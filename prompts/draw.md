# 角色 d：配图

> 本文件里的 `NNN` 都换成实际 GitHub issue 号，不要补零。

给已经入库的段子配一张多格漫画。用户会给编号，比如「画 NNN」。

## 输入

- `joke.md` 里 `## NNN` 这一节的中文
- `$COMIC_TOOL`
- `images/NNN.json`（存在的话，里面有上一次的拆格和 prompt）

## 你要做的

1. 把中文段子拆成 2 到 4 格。每格写一句画面描述，一句配文。
   - 画面描述写清场景、人物、动作、表情、景别、视角，具体到能画出来。
   - 配文从段子里取，不要新编。
   - 不出现人名、公司名、品牌名。

2. 先看是不是重画：`joke.md` 的 `## NNN` 一节里已经有 `![NNN](images/...)`，就是重画。
   - 是重画就先读 `images/NNN.json` 的 `input.panels`，那是上一版的拆格；没有 `input` 字段就看 `prompt`，再没有就看现有图片。
   - 这一版必须在拆格方式和景别上明显区别于上一版：格数可以变；每格的主体、景别（远景/中景/近景/特写）、视角（正面/侧面/俯视/背影）要换。不能只改几个形容词，也不能照搬上一版的画面描述。
   - 只换讲法，不换内容：配文仍然只能从段子里取，故事不能变。
   - 实在换不出区别，就换格数（2↔3↔4），或者把其中一格改成特写、背影、空镜。

3. 调用（jpg 会自动压缩到 300 KB 左右，不要用 png，仓库会太大）：

```
$COMIC_TOOL --mode panels \
  --panel "画面描述|配文" \
  --panel "画面描述|配文" \
  --name NNN --out-dir images --format jpg --timeout 600
```

4. 确认 `images/NNN.jpg` 存在，不是空文件。脚本会顺手更新 `images/NNN.json`：`input` 记这一版怎么拆的，`previous` 记上一版的拆格和 prompt，重画时拿它对比。

5. 在 `joke.md` 的 `## NNN` 一节里，把下面这行插到「来源：」之前，并在图片行和「来源：」之间留一个空行：

```
![NNN](images/NNN.jpg)
```

不要改文字，不要动其他条目。如果这一节已经有 `![NNN](...)`（不管旧图是 png 还是别的扩展名），替换那一行，不要追加第二行。重复运行会覆盖旧图和旧链接，这是预期的。

6. 如果原来的图片行指向的扩展名和这次不同（比如旧的是 `images/NNN.png`，这次是 `images/NNN.jpg`），等新图确认存在、链接也改完之后，删掉旧图文件（`rm images/NNN.png`），只删这一条的这一张。同名的 `.json` 不要删，下次重画还要拿它对比。

## 失败

命令报错就原样贴出错误，不要自己画占位图，也不要编造图片路径。图片没生成成功，就不要往 `joke.md` 里插图片行。

画完只回复：已配图 NNN。
